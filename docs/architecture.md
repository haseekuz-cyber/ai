# Архитектура

## Рабочее пространство

Controller и Worker работают в одной Windows-учётной записи. Пространство AI ограничено вторым монитором и выбранным окном. Отдельная ОС или вторая Windows-сессия не требуются.

```text
Пользователь, основной монитор        AI, второй монитор
┌─────────────────────────┐          ┌────────────────────────────┐
│ физическая мышь         │          │ выбранное окно приложения │
│ обычная клавиатура      │          │ синий AI-курсор           │
└─────────────────────────┘          └─────────────┬──────────────┘
                                                  │
                    ┌─────────────────────────────┴─────────────┐
                    │ Worker                                  │
                    │ UI Automation + Direct Window messages  │
                    │ снимок HWND + подтверждения + аудит     │
                    └────────────────┬──────────────────────────┘
                                     │ loopback
                    ┌────────────────▼──────────────────────────┐
                    │ LM Studio · Qwen3-VL 8B                  │
                    └───────────────────────────────────────────┘
```

## Цикл задачи

1. Worker делает снимок только выбранного HWND.
2. Локальная модель предлагает один следующий шаг и уровень риска.
3. Координаты привязываются к текущему UI-элементу, если он доступен.
4. Изменяющий шаг показывается пользователю и ждёт подтверждения.
5. Worker отправляет действие прямо целевому окну, не двигая системный курсор.
6. Новый снимок проверяется локальной моделью; затем планируется следующий шаг.

## Обучение показом

Режим обучения ограничивает запись одним выбранным окном. Физические демонстрации и действия синего AI-курсора преобразуются в шаги навыка. Для каждого шага сохраняются устойчивый селектор, относительная позиция и тип действия. Парольные поля исключаются. При повторе каждый шаг снова требует подтверждения и визуальной проверки.

## Безопасность

- окно должно находиться на назначенном втором мониторе;
- терминалы, Codex и ChatGPT запрещены как цели;
- физический системный курсор не используется;
- внешние приложения получают повышенный риск;
- низкая уверенность модели блокирует действие;
- аварийная остановка блокирует UIA, Direct Window, задачи и навыки;
- журнал действий не сохраняет вводимый текст.
