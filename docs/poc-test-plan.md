# План проверок

## 1. Граница второго монитора

- окно и точка действия находятся внутри `\\.\DISPLAY1`;
- снимок содержит только выбранное окно;
- цели на основном мониторе отклоняются.

## 2. Независимый ввод

- UIA-действия и Direct Window messages выполняются без `SetCursorPos` и `SendInput`;
- `systemPointer.usedByAction` равен `false`;
- движение физической мыши пользователем во время вызова не приписывается AI.

## 3. Подтверждения

- планирование не выполняет действий;
- каждый локальный изменяющий шаг требует `confirmed=true`;
- Telegram, браузеры и другие внешние приложения помечаются `external_effect`;
- низкая уверенность блокирует выполнение.

## 4. Обучение

- демонстрация ограничена выбранным окном;
- пароль и неидентифицированный чувствительный текст не сохраняются;
- навык повторно находит UI-элемент после изменения размера окна;
- каждый шаг навыка отдельно подтверждается и проверяется снимком после выполнения.

## 5. Аварийная остановка

- `Ctrl+Shift+F12` и кнопка `СТОП ИИ` блокируют новые действия;
- возобновление возможно только явной командой;
- событие записывается в аудит.

## 6. Реальные приложения

- Блокнот: полный цикл задачи и обучения — проверен;
- Telegram: только чтение и подготовка, отправка требует отдельного подтверждения;
- CorelDRAW: тестировать на пустом документе второго монитора, не затрагивая рабочий файл.
