# Локальное обучение UI-модели

Этот модуль отделён от LM Studio и основного Windows-исполнителя. Он создаёт только версионированный LoRA-адаптер; самостоятельно менять код, включать адаптер или выполнять действия на компьютере он не может.

## Каталоги

- Python: `D:\AI-Work\Training\.venv`
- исходная модель: `D:\AI-Work\Training\Models\Qwen3-VL-2B-Instruct`
- датасеты: `D:\AI-Work\Training\Datasets`
- адаптеры: `D:\AI-Work\Training\Adapters`
- кэш: `D:\AI-Work\Training\Cache` и `D:\AI-Work\Training\HuggingFace`

## Поток данных

1. Пользователь показывает действие и сохраняет демонстрацию.
2. Система связывает `before.png`, `after.png`, финальный визуальный референс, клавиши, модификаторы и траекторию.
3. `build_dataset.py` принимает только демонстрации с совпадающим проверенным финальным изображением и не более чем 64 логическими шагами.
4. `curate_with_teacher.py` просит локальную Qwen3-VL-8B проверить экран до/после и объяснить смысл каждого шага. Учитель не может менять действия, порядок, `Ctrl` или траекторию.
5. Произвольный пользовательский текст заменяется на `<USER_TEXT>`; числовые размеры сохраняются.
6. Обычное обучение требует минимум 200 проверенных примеров. Малый пилот разрешается явно только от 20 примеров.
7. Новый адаптер сохраняется в новом каталоге и получает `promoted: false`. Установка в рабочий агент выполняется только после сравнительного теста и подтверждения пользователя.

## Команды

```powershell
C:\Users\user\.lmstudio\bin\lms.exe server start --port 1234 --bind 127.0.0.1
C:\Users\user\.lmstudio\bin\lms.exe load qwen/qwen3-vl-8b --gpu 0.7 --context-length 8192 -y
D:\AI-Work\Training\.venv\Scripts\python.exe training\verify_environment.py
D:\AI-Work\Training\.venv\Scripts\python.exe training\build_dataset.py
D:\AI-Work\Training\.venv\Scripts\python.exe training\curate_with_teacher.py
D:\AI-Work\Training\.venv\Scripts\python.exe training\train_qlora.py
```

Новые демонстрации сохраняют отдельные визуальные кадры до и после каждого логического действия. Положительно оценённый шаг попадает в датасет только после успешной автоматической проверки и явного человеческого подтверждения, то есть в состоянии `training_approved`. Отрицательные и только интерпретированные эпизоды остаются в журнале опыта, но исключаются из SFT-датасета.

Старые записи без пошаговых кадров не считаются автоматически пригодными: локальный Qwen-учитель должен подтвердить их по общему состоянию до/после. Обучение никогда не запускается автоматически после лайка или демонстрации.

`train_qlora.py` не начнёт обучение при недостатке подтверждённых примеров. Для изолированного исследовательского прогона на 20–199 примерах нужен явный флаг `--allow-small-pilot`; такой адаптер нельзя автоматически включать в исполнитель.
